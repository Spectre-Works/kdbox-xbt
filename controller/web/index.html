Factory reset & reconnection

The miner is clearing owner settings and restarting. Wi-Fi will be disconnected and its IP may change. Reconnect with Ethernet, then use your router or the KD BOX XBT Installer to find it.

After completion, unlock with 123456789 and set up your new network and pool. The SSH root password returns to !@#$%123. Old dashboard sessions and SSH authorized keys are invalidated.

Controller unavailable

The dashboard page loaded, but the controller is not responding. Allow a few minutes after a restart and check the miner’s network connection.

If you used the original factory reset or reflashed stock firmware, launch the KD BOX XBT Installer and choose Back up & repair KD BOX XBT. A factory reset erases the controller and saved settings while this page can remain.

Restart & recovery

A restart briefly interrupts mining. Automatic performance recovers interrupted adjustments on startup.

Factory reset — keep the mod

Erase this owner’s settings. This removes pools, saved Wi-Fi networks, static IP/DNS settings, cloud credentials, device labels, tuning preferences and history. Dashboard and SSH passwords return to their factory defaults, and SSH authorized keys are removed.

The mod stays installed. Bitcoin (XBT), 740 MHz / 430 mV, a 75°C hottest-chip limit and Automatic performance off are restored. Genuine safety faults remain latched.

Wi-Fi disconnects and the miner reboots. Reconnect over Ethernet using your router or installer discovery; its IP may change. Default dashboard password: 123456789. Default SSH root password: !@#$%123.

Original firmware maintenance

Do not use the original factory reset to reset this mod. It erases the controller, settings and saved safety stops while leaving the dashboard page and startup hooks behind. Recovery requires the installer’s repair flow; erased settings need a matching private backup or manual reconfiguration. Firmware updates can also remove the mod or SSH access.
